# Protótipos de tela

Cada `*.dc.html` é uma tela do protótipo (HTML + CSS prontos, com dados fictícios). Servem de **referência visual e de estrutura** para o front-end real: cores, fontes, espaçamentos, textos e comportamento. Não são código de produção.

- `canvas.json`: posição e título de cada tela no canvas original.
- Numeração das telas: 1 Lista, 2 Cadastro, 3 Seleção para relatório, 4 Relatório (A4), 5 Login, 6 Primeiro uso, 7 Código de recuperação, 8 Recuperar senha, 9 Configurações e backup.
- As telas 7 e 8 mostram o código de recuperação em formato de exemplo; o formato final está como decisão adiada em `../PLANO.md`.
