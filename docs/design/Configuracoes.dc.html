Backup

Uma cópia de tudo: doadores, usuário e configurações. Serve para reinstalar o sistema ou mudar de servidor.

O arquivo é protegido pela senha que você escolher. Sem essa senha ele não abre, e ninguém consegue recuperá-la. Guarde em local seguro.

Criar backup

Mínimo de 8 caracteres.

backup-2026-10-30.rdb

Restaurar backup

Isso substitui todos os dados atuais (doadores, usuário e configurações) pelos do backup. Crie um backup antes, se quiser guardar o que existe agora.
