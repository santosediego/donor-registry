Informe o código de configuração

Ao iniciar pela primeira vez, o sistema gerou um código de configuração e o deixou no local onde está instalado. Assim, só quem tem acesso a esse local consegue criar o administrador.

8 caracteres. Maiúsculas e minúsculas não fazem diferença.

Onde encontro o código?

Instalei com Docker

Na pasta do projeto, rode docker compose logs. O código aparece em um quadro como este:

============================================ Registro de Doadores · configuração inicial Código de configuração: 7K4Q-M9XD Abra o endereço do sistema e informe o código. ============================================

Se você definiu SETUP_CODE no .env, o quadro avisa que está usando o seu código e não o mostra.

Instalei sem Docker

O mesmo quadro aparece no log de inicialização, no local onde o sistema foi iniciado, logo depois da mensagem de que ele subiu.

Não achei o quadro

O código também fica salvo no arquivo setup-code.txt, dentro da pasta de dados do sistema. O arquivo é apagado assim que o administrador é criado.

Se preferir escolher o código, defina SETUP_CODE no arquivo .env antes de iniciar, com 8 caracteres no mesmo formato (XXXX-XXXX). Esse código não muda quando o sistema reinicia.

Depois que o administrador é criado, esta tela deixa de existir.
